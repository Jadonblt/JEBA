RideIntervals v0.2.0

A self-contained interval timer for exercise bikes.

CURRENT VERSION
- Version: 0.2.0
- Before editing, read CHANGELOG.md to check what has already been changed.
- For each release, update the version in index.html, README.txt and CHANGELOG.md.

USE
1. Open index.html in any browser.
2. Choose a preset or customise the timings.
3. Press Start.

INPUT LIMITS
- Warm-up: 0-60 minutes
- Fast pedal: 5-3,600 seconds
- Recovery: 5-3,600 seconds
- Rounds: 1-200
- Cool-down: 0-60 minutes

HOSTING
- Upload index.html to your normal web hosting public_html folder.
- Or deploy the folder to GitHub Pages, Netlify, Cloudflare Pages or Vercel.

FILES
- index.html: complete web app
- README.txt: setup and version information
- CHANGELOG.md: release history and completed changes
